# Graph neural network

Una graph neural network apprende su dati con relazioni topologiche aggregando iterativamente informazioni dai nodi vicini. La fonte associa il message passing a classificazione di grafi o nodi, predizione di link e clustering, con applicazioni quali raccomandazione, molecole e knowledge graph.
