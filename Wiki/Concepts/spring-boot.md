# Spring Boot

Spring Boot è presentato nel materiale come piattaforma Java per applicazioni Spring autonome e pronte per la produzione, con configurazione iniziale ridotta. Il corso tratta annotazioni, dipendenze, contenitore servlet incorporato, endpoint REST e CRUD con JPA.
