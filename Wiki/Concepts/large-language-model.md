# Large language model

Un large language model è un modello neurale, tipicamente basato su Transformer, addestrato su grandi quantità di testo per predire token. Le fonti lo descrivono come un foundation model riutilizzabile per task downstream mediante prompting o adattamento.

Le varianti architetturali encoder-only, decoder-only ed encoder-decoder privilegiano rispettivamente comprensione, generazione o trasformazioni input-output. La disponibilità di un modello generalista non implica che sia una fonte di verità: la previsione statistica del testo non garantisce grounding nel mondo reale.
