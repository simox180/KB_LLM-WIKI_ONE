# Collezioni Java di base

`ArrayList` serve per sequenze indicizzate, `HashSet` per unicità e visitati, `HashMap` per associazioni chiave-valore e `ArrayDeque` per code, deque e pile. In un `ArrayList`, `set` sostituisce mentre `add` inserisce; una `PriorityQueue` non si riordina automaticamente se cambia la priorità interna di un elemento già inserito.
