# Long short-term memory

LSTM è una variante delle reti ricorrenti per dati sequenziali. Mantiene uno stato di cella e usa gate di input, forget e output per controllare cosa aggiungere, mantenere o restituire; le fonti la presentano come mitigazione delle difficoltà delle RNN con dipendenze lunghe e vanishing gradient.
