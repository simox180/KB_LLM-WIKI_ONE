•

: Gruppi di istanze che insieme costituiscono un'anomalia
•
Caratteristiche Chiave
: Rarità, deviazione significativa, significato informativo/operativo

•

: Distribuzione probabilistica, test statistici, intervalli di confidenza

: K
-
nearest
neighbors

: Identificazione di regioni a bassa densità nello spazio dei dati
•
Metodi di Machine Learning
: 
•
Supervisionati
: SVM, Random 
Forest
(quando sono disponibili esempi etichettati)
•
Semi
-
supervisionati
: One
-
class SVM, 
isolation
forest
(solo esempi normali)
•
Non supervisionati
: 
Autoencoder
, GAN, PCA (nessuna etichetta necessaria)
•
Deep Learning per Anomalie
: Reti neurali specializzate per sequenze temporali (LSTM) o dati complessi
Sfide Principali
•
Class 
Imbalance
: Eventi anomali naturalmente rari, dataset sbilanciati
•
Feature Engineering
: Identificazione delle caratteristiche più rilevanti per rilevare anomalie
•
Evoluzione dei Pattern
: Adattamento a concetti in evoluzione e drift
•
Falsi Positivi/Negativi
: Bilanciamento tra sensibilità e specificità
